🎯 Cómo funciona esta guía

Cada ejercicio combina una clase (con constructor, atributos y métodos) con colecciones (listas, tuplas, diccionarios, conjuntos) para resolver un problema real.

La estructura es siempre:

  • __init__: constructor que inicializa atributos (muchas veces colecciones vacías)
  • Método 1: resuelve una tarea concreta (recibe datos, procesa, retorna un resultado)
  • Método 2+: reutiliza el método 1 con *args o **kwargs para procesar lotes
🧱 Estructura de cada ejercicio

Paso 1 (Entender): Identifica la Entrada, Proceso y Salida.

Paso 2 (Bosquejo): Resuelve a mano con datos concretos.

Paso 3 (Patrón): Descubre qué se repite y qué cambia.

Paso 4 (Código): Escribe la clase y sus métodos.

Paso 5 (Verificación): Prueba con una tabla (trace execution).

Ejercicio 0 — Números primos: validar y listar
📋 Enunciado. Crear una clase NumeroPrimo que:
  • Tenga un método es_primo(numero) que retorne True o False.
  • Tenga un método primos_en_rango(*args) que reciba múltiples números y retorne una lista con los que son primos, reutilizando es_primo().
  • Tenga un atributo historial (una lista) que guarde todos los números probados.
  • Tenga un método cantidad_verificados() que retorne cuántos números se han probado.

Proceso

Salida

Ejemplo de entrada

Resuelvo a mano cómo determinar si un número es primo y cómo guardar el historial.

3Descubrir el patrón
💡 Aquí me doy cuenta de que…

1) Método es_primo(numero): Es un validador que usa un bucle for (control de flujo de Unidad 1). Prueba divisores desde 2 hasta √número. Si alguno divide exactamente (módulo == 0), retorna False. Si termina el bucle sin encontrar divisor, retorna True.

2) Método primos_en_rango(*args): Recibe múltiples números en *args. Recorre todos con un bucle, llama a es_primo() para cada uno, y si es primo lo añade a una lista. Esta es la reutilización.

3) Atributo historial: Es una lista que crece cada vez que se verifica un número. Se inicializa vacía en __init__ y se actualiza en cada método que ejecuta una verificación.

4) Constructor __init__: Solo inicializa el historial. No recibe parámetros complejos, solo prepara el estado inicial.

Conceptos aplicados: operadores aritméticos (%), control de flujo (for, if), funciones dentro de clases, colecciones (listas, tuplas via *args), reutilización de métodos.

4Escribir el código (clase y métodos)
Python — solución completa 
class NumeroPrimo:
    """Clase para validar números primos y guardar historial de búsquedas."""
    
    def __init__(self):
        # Historial: lista que guarda todos los números verificados
        self.historial = []
    
    def es_primo(self, numero):
        """Retorna True si numero es primo, False en caso contrario."""
        # Agregar a historial
        self.historial.append(numero)
        
        # Casos especiales
        if numero < 2:
            return False
        
        # Comprobar divisores desde 2 hasta sqrt(numero)
        for divisor in range(2, int(numero ** 0.5) + 1):
            if numero % divisor == 0:
                return False
        
        return True
    
    def primos_en_rango(self, *args):
        \"\"\"Retorna una lista con los números primos de los pasados en *args.\"\"\"
        primos = []
        for numero in args:
            if self.es_primo(numero):
                primos.append(numero)
        return primos
    
    def cantidad_verificados(self):
        \"\"\"Retorna cuántos números se han verificado.\"\"\"
        return len(self.historial)
    
    def limpiar_historial(self):
        \"\"\"Borra el historial.\"\"\"
        self.historial = []


# --- Programa principal ---
np = NumeroPrimo()

# Probar un número individual
resultado = np.es_primo(7)
print(f\"¿7 es primo? {resultado}\")

# Probar varios números a la vez
primos = np.primos_en_rango(10, 11, 12, 13, 14, 15)
print(f\"Primos en el rango [10-15]: {primos}\")

# Ver historial y cantidad
print(f\"Historial: {np.historial}\")
print(f\"Total verificados: {np.cantidad_verificados()}\")

5Prueba de escritorio (trace execution)

Simulo línea por línea la ejecución con datos concretos.

AcciónHistorialSalida
np = NumeroPrimo()[]—

⚠️ Errores que cometen casi todos
  • No inicializar self.historial = [] en __init__. Sin esto, el atributo no existe cuando llamas al método.
  • No reutilizar el método es_primo en primos_en_rango. Si escribes el código de validación dos veces, después es difícil de mantener.
  • Olvidar agregar append al historial. El método funciona pero el historial nunca crece.
  • Confundir *args con una lista. *args es una tupla; si necesitas una lista, crea una dentro del método.
  • Poner `*args` en el constructor. Los argumentos variables se usan mejor en métodos, no en `__init__`.
